# 🌐 Maqueta Cisco - Soluciones de Red

Proyecto web que simula una **página corporativa de Cisco**, destacando soluciones de red, infraestructura y seguridad utilizando **HTML, Bootstrap 5 y AOS** para animaciones.

## 🚀 Descripción

Esta maqueta web muestra un diseño profesional con un enfoque corporativo, incluyendo:

* Navbar responsivo con logo y login
* Hero section con imagen de fondo y texto overlay
* Secciones tipo damero alternando texto e imagen
* Estadísticas destacadas de tecnología
* Galería de servicios con interacción de collapse
* Redes sociales integradas mediante icons y accordion en móvil

## 🛠️ Tecnologías utilizadas

* **HTML5** – Estructura del sitio
* **CSS3 + Bootstrap 5** – Grid, diseño responsivo y componentes
* **Bootstrap Icons** – Iconografía
* **AOS (Animate On Scroll)** – Animaciones al hacer scroll
* **JavaScript** – Inicialización de AOS y funcionalidad collapse

## 📁 Estructura del proyecto

```bash
📦 Maqueta-Cisco
 ┣ 📜 index.html          # Página principal
```

## 🎨 Funcionalidades

1. Navbar fijo y responsive con menú colapsable en móvil.
2. Hero section con overlay de texto y efecto de brillo.
3. Secciones tipo damero que alternan texto e imagen.
4. Galería de servicios interactiva con collapse para descripciones.
5. Animaciones al hacer scroll mediante AOS.
6. Acceso a redes sociales con íconos responsivos.
